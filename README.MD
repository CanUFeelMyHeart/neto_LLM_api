# GigaChat Console

Консольное приложение на Python для взаимодействия с языковой моделью GigaChat через API.

## Возможности

- Получение Access Token через OAuth API.
- Отправка пользовательских запросов в GigaChat.
- Получение и отображение ответов модели в консоли.
- Настройка модели и параметров подключения через `.env`.
- Обработка ошибок HTTP и соединения.

## Технологии

- Python
- Requests
- Python-dotenv
- GigaChat API
